# Modern Real Estate Website
Building a modern looking real estate website using Vite, React, & Tailwind.

# Description
I wanted to go through and follow a basic tutorial to have a starting guideline, while still making improvements and adjusting to a slightly different use.

- Instead of using basic JavaScript, I wanted to use TypeScript and keep things more defined through-out.

- Converted sections of code into reusable components.

- Instead of having saved images and hard-coded information for now, I utilized FakerJS to randomize the data and keep it looking fresh each visit.

## Utilities
- [Faker.JS](https://fakerjs.dev/) - Generate massive amounts of fake (but realistic) data for testing and development.
